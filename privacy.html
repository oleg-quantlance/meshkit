Privacy Policy & Consent Mode v2 Settings

EFFECTIVE DATE: 2026-11-01 FILE UPLOADS: 0 BYTES (LOCAL ONLY)

1. Local Browser File Processing (Zero Uploads)

When you select or drag a `.gcode`, `.stl`, or `.step` file into any MeshKit tool, the file is read exclusively inside your web browser's local memory (`ArrayBuffer` / Web Worker). No file contents, 3D geometry, or file names are ever transmitted to any server.

2. Google Analytics 4 & Consent Mode v2

MeshKit uses Google Analytics 4 (GA4) configured with Consent Mode v2. By default, before any tag runs, `ad_storage`, `analytics_storage`, `ad_user_data`, and `ad_personalization` are set to denied. No analytics cookies (`_ga`) are stored unless you explicitly grant consent.

When analytics consent is granted, MeshKit sends only aggregate interaction events (`file_load_success` with coarse size bucket `<1 MB`, `1–10 MB`, `10–50 MB`, `>50 MB` and parse duration in milliseconds; `file_load_error` with error code; `calculate`; `export_download`; `sample_load`; and `internal_tool_link`). File names and file contents are never included in analytics parameters.
