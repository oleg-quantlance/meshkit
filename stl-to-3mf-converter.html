What the Online STL to 3MF Converter Does

STL is a 1987 format: a bag of triangles with no units, no object name and no way to say which way is up. 3MF (ISO/ASTM 52915) fixes all of that and is now the native format of Bambu Studio, OrcaSlicer, PrusaSlicer, Cura, Windows 3D Builder and Microsoft 3D Print. This converter reads a binary or ASCII .stl, welds coincident vertices into an indexed mesh, drops zero-area triangles, and writes a minimal, spec-conformant 3MF package — [Content_Types].xml, _rels/.rels and 3D/3dmodel.model — compressed with DEFLATE.

You choose the unit attribute (millimeter or inch) and an object name that will show up in your slicer's object list. Coordinates are written exactly as they appear in the STL; the unit tag tells the slicer how to interpret them. The mesh is audited for open edges so you know whether to run STL Repair first. Everything runs in a Web Worker in your browser; the file is never uploaded.

How to Convert STL to 3MF in 3 Steps

  1. Drop your .stl: Binary and ASCII STL are detected automatically (never by the solid prefix alone, which many binary exporters also write). Files up to 100 MB.
  2. Set unit and name: Leave Millimeter unless you know the STL was exported in inches. Type an object name if you want something better than the filename in your slicer's object list.
  3. Export .3mf: The log reports welded vertex count, triangle count, output size and watertightness. Click Export .3MF and open the file directly in Bambu Studio, OrcaSlicer, PrusaSlicer or Cura.

Worked Example: Vertex Welding and File Size

Binary STL bytes = 84 + 50 × N_triangles (each corner stored again for every facet)
3MF: V unique vertices + N index triples in XML, then DEFLATE
20 mm cube: STL 684 bytes (36 corners) → 3MF 8 vertices + 12 triangles ≈ 1.1 KB zipped (XML overhead dominates tiny meshes)
150 k-facet organic part: STL 7.5 MB → 3MF typically 1.5–2.5 MB

Welding uses exact coordinate matching after rounding to six decimals, so it merges the duplicate corners STL creates without moving any vertex. It does not close gaps between faces that were never coincident — that is a repair step, not a conversion step.

Why Convert STL to 3MF?

  • Units travel with the file: no more 25.4× surprises when a model made in inches lands in a millimetre slicer.
  • Smaller files: indexed vertices plus compression typically cut size by 3–5× versus binary STL and 15–25× versus ASCII STL.
  • Named objects: the name you type here appears in the slicer's object list and in MakerWorld/Printables uploads.
  • A starting point for projects: open the 3MF in your slicer, add settings, and save — the geometry part is already in the right place.

Technical Limitations

The output contains geometry and metadata only: no printer profile, filament settings, colours, textures or thumbnails. Multiple shells inside one STL stay one object (3MF allows that). Per-face colour from binary STL attribute bytes is not carried over. If the input mesh has open edges, the 3MF will have them too — most slicers still load it, but repair first for a clean solid.

Frequently Asked Questions

Will Bambu Studio, OrcaSlicer, PrusaSlicer and Cura open the file?

Yes. The package follows the 3MF Core specification exactly (content types, root relationship, one model part with a mesh object and a build item), which is the subset every slicer's importer supports. It opens as a plain geometry 3MF, not a project with settings.

Should I choose millimeter or inch?

Millimeter, unless the STL was exported from a CAD tool set to inches and looks about 25× too small when opened in a slicer. The converter never rescales coordinates; the unit attribute tells the slicer how to interpret them.

Why is the 3MF sometimes larger than a tiny STL?

For very small meshes the XML and ZIP container overhead (about 1 KB) outweighs the savings from vertex indexing. From a few hundred triangles upward the 3MF is smaller, and for typical printable parts it is several times smaller.

Does welding change the geometry?

No vertex is moved. Corners that are bit-identical after rounding to six decimal places share one index, and triangles whose three corners collapse to fewer than three unique points are removed. Volume and surface area are unchanged.

Is anything uploaded?

No. Parsing, welding and ZIP writing all happen in a Web Worker in your browser. The exported file is created from browser memory with a download link.

Reference // Why 3MF Is Smaller

STL stores every triangle's three corners independently, so a shared vertex is written up to six times. 3MF stores a vertex list once and indexes it, then the whole package is DEFLATE-compressed. Typical result: 3–5× smaller than binary STL with identical geometry.
