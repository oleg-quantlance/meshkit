What the Online 3MF to STL Converter Does

3MF (3D Manufacturing Format, ISO/ASTM 52915) is the project format written by Bambu Studio, OrcaSlicer, PrusaSlicer, Cura and Windows 3D Builder. It is a ZIP package holding an XML model part plus optional thumbnails, print settings and plate layout. Most CAD tools, mesh repair utilities, online print services and older slicers still want a plain .stl. This converter opens the package in your browser, resolves every object placed on the build plate, applies the component and build-item transforms, converts the declared unit (millimeter, inch, micron, centimeter, foot or meter) to millimetres, and writes a single STL.

It understands the 3MF Core specification and the Production extension used by slicer project files, where each model lives in its own part under 3D/Objects/ and is referenced through p:path. Support and surface objects are skipped so only printable geometry reaches the STL. The result is audited for open edges before download, and the file never leaves your machine — there is no upload, no queue and no size cap beyond your browser's memory (100 MB package limit).

How to Convert 3MF to STL in 3 Steps

  1. Drop your .3mf file: Click the upload area or drag a 3MF package from Bambu Studio, OrcaSlicer, PrusaSlicer, Cura, Fusion or Windows 3D Builder. The ZIP is unpacked in browser memory.
  2. Pick the STL encoding: Binary STL is the default and what every slicer and print service expects. Choose ASCII STL only if a downstream tool specifically requires text.
  3. Review and export: Check the bounding box, triangle count, number of merged objects and output size in the log, then click Export .STL. Multi-object plates are merged into one mesh with their plate positions preserved.

Worked Example: Plate Transforms and Units

A 3MF component or build item carries a 3×4 affine matrix written row-major as twelve numbers. Each vertex is transformed as a row vector, then scaled by the model unit:

transform="m00 m01 m02 m10 m11 m12 m20 m21 m22 m30 m31 m32"
x' = x·m00 + y·m10 + z·m20 + m30  (likewise y', z')
Sample package: 20 mm cube at (−10, −10, 0) + Ø12 × 8 mm boss offset (10, 10, 20) → one STL, 204 facets, 8.90 cm³
unit="inch" ⇒ every coordinate × 25.4 before writing STL

If a transform mirrors the part (negative determinant), triangle winding is flipped so the STL keeps outward normals and a positive signed volume. Open STL Volume & Weight on the result to confirm.

Why Convert 3MF to STL?

  • Sharing on Printables, Thingiverse or MakerWorld: STL remains the universal download format and the one most viewers render.
  • Mesh editing: Meshmixer, Blender importers and many CAD "insert mesh" dialogs accept STL but not slicer-specific 3MF projects.
  • Print services and older firmware tools: Quote engines and legacy slicers (Simplify3D 4, older Cura builds) still expect STL.
  • Stripping slicer metadata: A project 3MF carries your printer profile, filament settings and thumbnails; the STL contains geometry only.

Technical Limitations

Colour, material and texture information (the 3MF Materials extension), beam lattices, slice-stack extensions and per-object print settings are not representable in STL and are discarded. Multiple build items become a single merged mesh; if you need one STL per object, open the project in your slicer and export each object separately. Encrypted (Secure Content) 3MF packages are not supported.

Frequently Asked Questions

Is my 3MF file uploaded anywhere?

No. The ZIP is unpacked and the XML parsed in a Web Worker inside your browser. The only network request the page makes is for the sample file if you click "Load sample".

Does it work with Bambu Studio and OrcaSlicer project files?

Yes. Those projects keep the plate in 3D/3dmodel.model and each part under 3D/Objects/object_N.model, referenced through the Production extension's p:path. The converter follows those references, applies the plate transforms and skips support/modifier objects.

My plate had three parts — why do I get one STL?

STL has no concept of separate objects, so everything on the plate is merged into one mesh with positions preserved. The "Objects merged" counter tells you how many meshes went in. For per-part files, export each object from your slicer.

Why does the STL come out at a different size than I expected?

3MF files declare a unit; the converter scales to millimetres, which is what slicers assume for STL. A model authored in inches is multiplied by 25.4. If the bounding box in the log looks 25× too big or too small, the source file's unit attribute is wrong — fix it in the source or scale in the slicer.

Binary or ASCII STL?

Binary. It is exactly 84 + 50 × N bytes, loads faster, and is what every slicer expects. ASCII STL is 4–6× larger and only useful when a tool requires readable text.

Reference // 3MF Package Anatomy

A .3mf file is a ZIP. _rels/.rels points at the model part (normally 3D/3dmodel.model), which lists mesh objects, component assemblies with 3×4 transforms, and the build items actually placed on the plate. Slicer projects add Metadata/ and per-object parts under 3D/Objects/.
